Meydan AI · System Architecture

Request path for the main user action ("Generate a website"): The user submits a brief from the React generator UI → the request reaches the ALB through CloudFront → the ALB forwards /api/* to the FastAPI service → FastAPI writes a job to Redis → the Worker reads the job, calls OpenAI (Stage 0+1) and Anthropic (Stage 2+3), persists progress to Postgres, and finally uploads the generated site to S3. The Worker streams progress events back to the user through Server-Sent Events on the same ALB connection.
